# Movie_Searcher
A simple movie search application built with React, Vite, and Tailwind CSS.
 
## Features
 
- Search for movies by title
- View movie details including plot, cast, director, ratings
- Clean and modern UI
 
## Getting Started
 
```bash
npm install
npm run dev
```
 
## Tech Stack
 
- React
- Vite
- Tailwind CSS
- OMDB API
